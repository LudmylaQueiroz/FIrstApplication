## Como executar

1. Instale o [Android Studio](https://developer.android.com/studio).
2. Clone o repositório ou baixe o ZIP e extraia.
3. No Android Studio, vá em **File > Open** e selecione a pasta do projeto.
4. Aguarde o Gradle sync terminar.
5. Crie ou selecione um emulador no **Device Manager** (ou conecte um celular Android com depuração USB).
6. Clique em **Run** (▶).

## Arquivos principais

- `app/src/main/res/layout/activity_main.xml`: layout da tela
- `app/src/main/java/com/rafael/firstapplication/MainActivity.kt`: lógica do botão e do Toast
